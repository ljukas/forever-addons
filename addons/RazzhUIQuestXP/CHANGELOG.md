# RazzhUIQuestXP

## Unreleased

- New: a line of text shows how much experience turning in all your completed quests gives, and how much of your current level that is, for example "Quests: +4,250 XP (31%)". It turns green when the turn-ins are enough to level up, and is hidden when you have no completed quests. Hover it for the details: how many quests, where your experience ends up, and any experience buff that is counted in.
- Open Edit Mode and drag the Quest XP box to place the line; its dialog has a Font Size slider. Each Edit Mode layout keeps its own place and size.
- A Quest XP page under Options → AddOns → RazzhUI has a button that opens Edit Mode.
