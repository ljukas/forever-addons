# RazzhUI

## Unreleased

- Adds a RazzhUI entry to the Esc menu, which opens the addon's Options page.
- Adds a RazzhUI page under Options → AddOns, with a Modules section where you switch each installed RazzhUI module on or off. Changes take effect after a reload.
- Each module that is on gets its own options page under RazzhUI.
- Adds a RazzhUI button to the minimap, which opens the addon's Options page. Drag it around the minimap's edge to move it, or hide it with "Show minimap button" on the RazzhUI page.
