# ForeverCombatText

## Unreleased

- The scrolling combat text for what happens to you (damage taken, heals, blocks, dodges) can be moved: open Edit Mode and drag the Combat Text box. Its dialog sets how far the text scrolls, how long it stays and how big it is, and each Edit Mode layout keeps its own. Which events show, and whether the text scrolls up, down or in an arc, are still set under Options > Combat.
